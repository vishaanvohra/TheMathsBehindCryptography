# The Mathematics Behind Encryption

A mathematical investigation into the principles underlying modern cryptographic algorithms, with a focus on RSA encryption and the implications of quantum computing for cybersecurity.

## Overview

This project explores how mathematical concepts from number theory, group theory and modular arithmetic underpin modern cryptographic systems.

The investigation compares symmetric and asymmetric encryption before examining the construction and operation of RSA in detail. It also considers how Shor's algorithm could affect the security assumptions underlying RSA and discusses the development of post-quantum cryptography.

## Topics Covered

* Cryptography and its historical development
* Symmetric vs asymmetric encryption
* Number theory in cryptography
* Group theory and cryptographic systems
* RSA key generation and encryption
* Modular arithmetic and Euler's totient function
* Shor's algorithm and quantum computing
* Post-quantum cryptography
* Future challenges in cybersecurity

## Project Work

The project includes mathematical derivations and worked examples of RSA key generation, encryption and decryption, including an example using modular arithmetic and the Extended Euclidean Algorithm.

The investigation was written in LaTeX and developed as a mathematics and computing project at Barton Peveril Sixth Form College.
